# FC3 MP

Public client downloads for Far Cry 3 Multiplayer.

## Install

1. Open [Releases](https://github.com/minosy-games-sdk/fc3-mp-releases/releases/latest).
2. Download the client ZIP and extract the complete folder to a writable location.
3. Run **updater.exe** to check, download, install and start the current client.

Requires the licensed Ubisoft Far Cry 3 DX9 v1.06 build on Windows and a signed-in Ubisoft Connect account.
Keep the CEF runtime files beside the updater. Do not start fc3-mp-launcher.exe directly.
Close running clients before updating. Client and server releases must match.

Only the client runtime is distributed here. Source, server and development tools remain private.
Individual release assets and manifest.json support automatic updates; users should download the ZIP.
